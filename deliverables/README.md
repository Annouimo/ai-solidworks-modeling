# 平面立体(2) — 建模成果

本批通过 SolidWorks 2025 COM API 创建原生草图、放样和切除特征，没有以外部 STEP 导入代替建模。特征名称沿用软件默认中文名称。

## 文件位置

- SolidWorks/：零件1～零件20.SLDPRT，另保留 3 个以“试验_”开头的早期模型。
- STEP/：零件1～零件20.STEP，另保留 2 个以“试验_”开头的早期导出。
- ../scripts/：所有项目脚本和旧宏集中保存。当前批量入口为 Run-BatchModels.ps1，模型定义为 BatchModels.cs。
- previews/：每件模型的前视图（_1）、上视图（_5）、右视图（_4）、等轴测图（_7），以及总览图。
- checks/：逐件检查记录、批次调试日志和已保存原生文件的复核表。

用户放入 demo/ 的原始示例保持原位，没有混入本批成果。失败的手写 STEP 不是有效成果，保留为 archive/step-import-attempt/*.failed.txt。

## 验证与精度

每个编号模型均检查：单个实体、正体积、特征错误码、SLDPRT 保存结果；STEP 导出后重新导入检查单实体与体积，允许最大 0.1 mm³ 或 0.001% 的数值差（取较大者）。随后重新打开原生文件副本验证保存内容。

这些图没有尺寸，因此整体大小、槽宽和斜率为按图估算。已人工检查导出的模型视图，但不宣称完成了所有投影线段的自动精确配准。第 18、19 页的通孔与斜底面也按给定投影做了几何解释；建议优先核对这两件复杂模型。

## 重运行

从项目根目录运行：

```powershell
powershell.exe -NoProfile -File .\scripts\Run-BatchModels.ps1
# 仅重建指定编号
powershell.exe -NoProfile -File .\scripts\Run-BatchModels.ps1 -Ids '13,19,20'
# 复核保存结果
powershell.exe -NoProfile -File .\scripts\Inspect-Deliverables.ps1
# 刷新总览图
powershell.exe -NoProfile -File .\scripts\Make-Overview.ps1
```

运行会重建并覆盖指定编号的成果文件。需先启动 SolidWorks；Codex 调用可能需要沙箱外权限。接口库安装路径在脚本里配置。历史脚本与早期单件测试不属于批量交付流程，其输出目录可能仍指向 results/，不建议直接运行历史脚本。
